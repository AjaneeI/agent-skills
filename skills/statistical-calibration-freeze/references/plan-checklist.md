# Statistical analysis plan checklist

- Primary estimand and population
- Unit of inference, clustering, pairing, family weighting
- Number of tasks, repeats and matched conditions
- Calibration simulation data-generating settings and seeds
- Proposed uncertainty procedure and implementation fingerprint
- Coverage / false-positive / width and failure diagnostics
- Handling of failed tools, missing runs, exclusions, reruns
- Multiplicity and secondary analysis hierarchy
- Minimum worthwhile gain / tolerable loss
- Freeze commit, approval, held-out exposure time
- Sensitivity analyses specified before results
